Flash USD

Custom ERC-20 Fixed Supply 180-Day Transfer Window

Flash USD is a custom ERC-20 token created for private testing, wallet integration practice, and controlled demos. It is an independent project token and is not affiliated with any third-party stablecoin issuer.

Core behavior includes a fixed mint supply at deployment and an on-chain transfer validity window measured from deployment time.

Always verify the exact contract address before importing or transferring tokens. Do not confuse this project with any other similarly named asset.
